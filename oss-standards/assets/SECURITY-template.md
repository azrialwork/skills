# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Do not open a public issue.** Report privately via one of:

- GitHub: `https://github.com/<owner>/<repo>/security/advisories/new`
- Email: `<security@example.com>`

We aim to acknowledge reports within 48 hours. Fixes are released as
patch versions together with a coordinated public advisory.
